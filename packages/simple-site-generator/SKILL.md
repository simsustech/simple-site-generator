# simple-site-generator

This is a thin pointer. **All instructions live in one place so there is exactly one copy:**

    packages/simple-site-generator/AGENTS.md

Read that file before generating a site. In a scaffolded project the same file is available at
`node_modules/simple-site-generator/AGENTS.md`, and `CONTENT-BLUEPRINT.md` next to it covers what to
write.

Do not duplicate its contents here — duplicated instructions drift, and a stale anti-pattern list is
worse than none.
